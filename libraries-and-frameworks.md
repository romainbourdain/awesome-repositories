# Libraries & frameworks

Building blocks for your own projects.

### [browser-use/browser-use](https://github.com/browser-use/browser-use)
Open-source Python library for AI browser agents. Also offers Browser Use Cloud, with stealth browsers and a hosted agent API.
- **Stack**: Python

### [D4Vinci/Scrapling](https://github.com/D4Vinci/Scrapling)
Web scraping framework that covers everything from a single request to a full-scale crawl.
- **Stack**: Python

### [tauri-apps/tauri](https://github.com/tauri-apps/tauri)
Build smaller, faster and more secure desktop and mobile apps with a web frontend.
- **Stack**: Rust
