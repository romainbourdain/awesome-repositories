# Awesome repositories

A personal collection of GitHub repositories I like, grouped by type, each with a short note.

## Categories

| Category | What's inside |
| --- | --- |
| [Skills](skills.md) | Agent skills, `CLAUDE.md` files, guidance packs |
| [Agents & MCP](agents-and-mcp.md) | Agent runtimes, memory layers, MCP servers |
| [CLI](cli.md) | Command-line tools |
| [Libraries & frameworks](libraries-and-frameworks.md) | Building blocks for projects |
| [Apps](apps.md) | Self-hostable and local-first applications |
| [Learning](learning.md) | Handbooks, best-practice guides, reading lists |
| [Lists & resources](lists-and-resources.md) | Curated lists and free resources |

## Adding a repository

Add an entry to the matching category file:

```md
### [owner/repo](https://github.com/owner/repo)
One sentence on what it does.
- **Stack**: main language
```

Create a new category file and add it to the table above when nothing fits.
