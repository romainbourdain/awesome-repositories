# Skills

Agent skills, `CLAUDE.md` files and guidance packs that shape how a coding agent behaves.

### [mattpocock/skills](https://github.com/mattpocock/skills)
Matt Pocock's personal collection of skills from his `.agents` directory, aimed at real engineering work.
- **Stack**: Shell

### [anthropics/skills](https://github.com/anthropics/skills)
Anthropic's official public repository of Agent Skills. The reference for the skill format.
- **Stack**: Python

### [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)
A single `CLAUDE.md` file that improves Claude Code's behavior, derived from Andrej Karpathy's observations on LLM coding pitfalls.
- **Stack**: none, one Markdown file

### [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)
Skills that give coding agents taste: art direction, reference images and a browser check, instead of generic AI-looking pages.
- **Stack**: JavaScript

### [pbakaus/impeccable](https://github.com/pbakaus/impeccable)
A design vocabulary for your coding agent. Steer with commands like `polish` and `bolder`, review with `critique` and `audit`, and catch AI slop before it ships.
- **Stack**: Rust

### [dietrichgebert/ponytail](https://github.com/dietrichgebert/ponytail)
Makes the agent think like the laziest senior dev in the room: the best code is the code you never wrote.
- **Stack**: JavaScript

### [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman)
A skill plus a local proxy that cuts token use: shorter answers and smaller tool output, with every original still recoverable.
- **Stack**: Go

### [GoogleChrome/modern-web-guidance-src](https://github.com/GoogleChrome/modern-web-guidance-src)
Keeps your coding agent up to date with current web best practices. Maintained by the Chrome team.
- **Stack**: TypeScript

### [NVIDIA/SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator)
Multi-tier framework for evaluating agent skills and plugins: quality gates, security scanning, harness compatibility, overlap detection, synthetic datasets and live agent evaluation. Ships reusable CI templates.
- **Stack**: Python

### [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify)
Turns a codebase, with its docs, SQL schemas, configs and PDFs, into a queryable knowledge graph. Ships a `/graphify` skill for Claude Code, Cursor, Codex and Gemini CLI. Parsing is local and AST-based, every edge is explained, and there is no vector store.
- **Stack**: Python
