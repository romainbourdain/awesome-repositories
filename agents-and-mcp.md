# Agents & MCP

Agent runtimes, memory layers, MCP servers and multi-agent frameworks.

### [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem)
Persistent context across sessions. Captures what the agent does, compresses it with AI and injects the relevant parts into future sessions. Works with Claude Code, Codex, Gemini, Copilot, OpenCode and others.
- **Stack**: TypeScript

### [bytebase/dbhub](https://github.com/bytebase/dbhub)
Token-conscious database MCP server for Postgres, MySQL, SQL Server, Oracle, MariaDB, SQLite and ClickHouse.
- **Stack**: TypeScript

### [earendil-works/pi](https://github.com/earendil-works/pi)
AI agent toolkit: unified LLM API, agent loop, TUI and a coding agent CLI.
- **Stack**: TypeScript

### [paperclipai/paperclip](https://github.com/paperclipai/paperclip)
Open-source app for managing agents at work.
- **Stack**: TypeScript

### [google-research/paper-orchestra](https://github.com/google-research/paper-orchestra)
Multi-agent framework for automated AI research paper writing, from Google Research.
- **Stack**: Python

### [BaaRai/ARTEX](https://github.com/BaaRai/ARTEX)
AI autonomous penetration testing system. This is the English translation of Autumn-27/ARTEX, under AGPL-3.0. Use it only on systems you are authorized to test.
- **Stack**: Go
